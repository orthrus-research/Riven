# Sources and licenses

Research was consulted on 2026-10-19. Geometric algorithms and synthetic fixtures were authored for this contribution; no terrain implementation, numerical geology tables, assets or textures were copied. These are bounded visual geometry recipes, not erosion or geological-history simulations.

- R. W. Gallois, **The Wealden district**, BGS, fourth edition (1965), [coastal account](https://webapps.bgs.ac.uk/memoirs/docs/B06880.html). Conceptual evidence for resistant-bed headlands, joint-guided arches/stacks and cliff/platform relationships. Source states Crown copyright 1965. Reference only; no text, maps or illustrations redistributed. This informed families 1–3, without copying its dimensions or coastline data.
- U.S. National Park Service, [**Sea/Littoral Caves**](https://www.nps.gov/subjects/caves/sea-or-littoral-caves.htm), updated 2022-04-27. Fractures and bedding weaknesses motivate joint-directed reentrants; through-openings and retained roofs distinguish an arch from a heightfield. Reference only; no illustrations, photographs or text redistributed. NPS pages include individually credited content; no blanket reuse license for those assets is assumed.
- U.S. National Park Service, [**Sea Arches**](https://www.nps.gov/havo/learn/nature/sea-arches.htm), updated 2020-03-31. Qualitative cliff/cave/arch/stack relationships inform family 4. No active lava generation or reconstructed erosion history follows from this reference. Reference only; no source assets redistributed.
- Sebastiano Vigna, [**splitmix64.c**](https://prng.di.unimi.it/splitmix64.c) (2015). The shared `mix` primitive uses its standard two-multiply finalizer and constants, adapted to Java unsigned shifts. This utility is distinct from the independently authored terrain kernels. The source dedicates the software to the public domain and grants unrestricted use/copy/modification/distribution, with an as-is warranty disclaimer; retain the notice below.
