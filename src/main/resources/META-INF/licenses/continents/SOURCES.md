The six-node swept-spine geometry, compact outward bay cuts, inverse-shear anchor admission, reservation precedence and bounded composition were derived for these kernels from elementary analytic geometry. The integer avalanche mixer uses conventional SplitMix64 finalizer arithmetic ([Steele, Lea and Flood, OOPSLA 2014](https://gee.cs.oswego.edu/dl/papers/oopsla14.pdf), ACM copyright), with explicit world/family/cell/slot separation. No third-party PRNG classes or terrain/noise library were copied or bundled.

New Java/Python source and authored prose in this directory use the accompanying **MIT** license. NumPy and Matplotlib are optional plotting dependencies only ([NumPy license](https://numpy.org/doc/stable/license.html), [Matplotlib license](https://matplotlib.org/stable/project/license.html)); their own licenses apply to them. The Riven height and scale definitions and runtime lock the kernels read remain Riven project inputs under their existing terms.
